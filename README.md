## What is NexaStore?

NexaStore is an open source, white-label AI commerce platform that any business can deploy, brand, and run as their own — for any product, any market, anywhere in the world. It ships with a fully autonomous AI operations layer, a production-ready storefront, 24 API routes, and a one-command setup path. Fork it, brand it, and go live in minutes.

## What Makes It Powerful

- **🤖 Haya AI Brain — 6 autonomous agents** that run your business for you: CFO, CMO, CRO, Inventory, Demand, and Chat agents operating continuously without human instruction
- **📊 Mission Control dashboard** — 7-panel business intelligence giving you live sales, inventory health, order pipeline, customer signals, and AI agent activity in one view
- **🌍 Full bilingual support** — English and Arabic built in, RTL-aware layout, extensible to any language without code changes
- **💱 Multi-currency, configurable tax** — set your currency, decimals, and tax rates per deployment with a single environment variable
- **🔐 Enterprise-grade security** — JWT authentication, OTP login, bcrypt password hashing, account lockout, rate limiting, and CRON_SECRET agent protection
- **⚡ 24 production-ready API routes** — auth, cart, orders, payments, AI enrichment, autonomous agents, and admin — all wired and ready

## Quick Start

```bash
git clone https://github.com/docsivan/nexastore.git
cd nexastore
cp .env.example .env.local   # fill in your API keys
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — your NexaStore is running.

> Full environment variable reference in the [docs](#).

## White Label in 4 Steps

**1. Change your brand name** — update the name and logo in `tailwind.config.ts` and your layout  
**2. Set your currency** — one environment variable controls all pricing, decimals, and tax display  
**3. Add your products** — populate your Airtable base with your catalogue; the platform is ready  
**4. Deploy** — push to Vercel or Kuberns; your branded AI commerce platform is live

That's it. No forks to maintain. No licensing fees. No vendor lock-in.
